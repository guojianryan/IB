# IB DP Computer Science

Revision pages for the IB Diploma Programme Computer Science course, first assessment 2027. The landing page lists every sub-topic in Theme A and Theme B. B2, programming, and B3, object-oriented programming, are the topics with lessons so far.

```bash
python3 -m http.server 8765
```

Then open `http://localhost:8765/`. B2.1 to B2.5 are the programming topics, in Python 3. Recursion on B2.4 is HL only. B3.1 is the single-class topic, for SL and HL. B3.2 is multiple classes, HL only. B3 keeps a Java fragment where the syllabus point is compile-time overloading.
