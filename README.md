# IB DP Computer Science

Revision pages for the IB Diploma Programme Computer Science course, first assessment 2027. The landing page lists every sub-topic in Theme A and Theme B. B3, object-oriented programming, is the topic with lessons so far.

```bash
python3 -m http.server 8765
```

Then open `http://localhost:8765/`. B3.1 is the single-class topic, for SL and HL. B3.2 is multiple classes, HL only. Code on both pages is Python 3, with one Java fragment where the syllabus point is compile-time overloading.
